# 🛡️ Personal Portfolio Website | Web Piscine Capstone

A clean, responsive, and accessibility-focused personal portfolio website built completely from scratch using pure **HTML5**, **CSS3**, and **Vanilla JavaScript**. 

Designed with a modern cybersecurity theme, this project features dynamic light/dark mode toggling, full English/Arabic internationalization with RTL support, and custom responsive layouts without relying on any external frameworks or libraries.

---

## ✨ Features

- **100% Authentic Craftsmanship:** Built completely from scratch (No Bootstrap, Tailwind, or external CSS/JS libraries).
- **Fully Responsive Layout:** Optimized across all screen sizes (Desktop, Tablet, Mobile down to 375px) using CSS Flexbox, Grid, and Media Queries.
- **Dynamic Theme Switcher:** Smooth Light/Dark mode toggling with state persistence via `localStorage`.
- **Full Bilingual & RTL Support:** Instant switching between English (LTR) and Arabic (RTL) with dynamic DOM updates using a custom JSON translation object.
- **Clean Structure:** Standardized semantic HTML elements for optimal SEO and accessibility.

---

## 🛠️ Tech Stack & Concepts

- **Markup:** HTML5 (Semantic elements)
- **Styling:** Modern CSS3 (CSS Variables, Flexbox, CSS Grid, Media Queries)
- **Scripting:** Vanilla JavaScript ES6+ (DOM Manipulation, Event Listeners, LocalStorage API)
- **Version Control:** Git & GitHub (Structured progressive commit history)
